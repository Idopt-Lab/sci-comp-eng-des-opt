# Lesson 5 — Uncertainty quantification

Lessons 2–4 treated every coefficient as exactly known. Real
designs live with uncertainty — tolerances, material scatter, operating conditions.
This lesson makes four Sellar parameters *random*, propagates that uncertainty to the
outputs, and then **reformulates the optimization in terms of statistics** so the
design is reliable, not just optimal-on-paper. It uses NASA's **UQPCE**
polynomial-chaos tooling, applied to the **same canonical Sellar problem** from
Lessons 2–4 — so the deterministic (mean-value) optimum is the familiar
`f* = 3.183394`, and adding the scatter is the only new ingredient.

Every script is runnable and writes committed `outputs/` (PNG/MD) so the figures
render on GitHub without re-running. Run from the repository root with the
`eng-des-opt-course` environment active. Scripts 3–4 need the `uqpce` package
(`pip install .[uq]`); scripts 1–2 need only numpy/scipy.

## The uncertain Sellar model

This is the **same canonical Sellar problem as Lessons 2–4**, with four coefficients
turned into random *multiplicative* factors. Crucially, **every factor has mean 1**,
so at the mean values the equations reduce exactly to the classic Sellar MDA and the
deterministic optimum is the familiar `f* = 3.183394` (OpenMDAO's canonical result).

```
y1  = a0*z1^2 + z2 + x - 0.2*y2
y2  = a1*sqrt(y1) + a2*z1 + z2
obj = x^2 + z2 + a3*y1 + exp(-y2)
g1  = 3.16 - y1 <= 0,   g2 = y2 - 24 <= 0        (classic Sellar constraints)
```

with `a0 ~ N(1, 0.06)`, `a1 ~ U(0.9, 1.1)`, `a2 ~ N(1, 0.05)`, `a3 ~ N(1, 0.10)`. The
factors sit on terms that are **non-zero at the optimum** (`z1`, `sqrt(y1)`, `y1`) so
each one actually influences the response there. At the deterministic optimum `g1` is
active (`y1 = 3.16`), so scattering `a0` scatters `y1` and violates `g1` ~half the
time; `g2` keeps a wide margin and never binds.

## Forward UQ and the robust reformulation

```
deterministic:   min  obj           s.t.  g <= 0            (ignore the scatter)
robust:          min  E[obj]         s.t.  CI_upper(g) <= 0   (feasible under scatter)
```

(The constraints are in classic `g <= 0` form, so robust feasibility requires the
*upper* confidence bound `CI_upper(g) <= 0` — even the worst-case draw stays feasible.)

**Monte Carlo** draws many input samples and runs the model at each — simple and
trusted, but expensive. **Polynomial chaos (UQPCE)** fits a polynomial in the random
inputs from a small *designed* set of runs, then reads `mean`/`variance` straight off
the coefficients and samples the cheap surrogate for the rest — the same statistics
for ~1000× fewer true model runs, which is what makes UQ affordable *inside* an
optimizer.

## Terminology cheat sheet

- **Aleatory** uncertainty — irreducible randomness, modeled with a distribution.
  **Epistemic** uncertainty — lack of knowledge, often modeled with intervals.
- **Forward propagation** — pushing input distributions through the model to get the
  output distribution. **Confidence interval** — the `(1 − significance)` central
  range of a response (here 95%).
- **Sobol indices** — variance-based global sensitivity: the fraction of output
  variance attributable to each input (`S_i` first-order, `S_Ti` total).
- **Polynomial chaos expansion (PCE)** — a surrogate expanded in orthogonal
  polynomials of the random inputs; **collocation / run matrix** — the designed
  sample points where the true model is run to fit it.
- **Robust optimization** — optimize a statistic of the objective (`E[obj]`) subject
  to probabilistic/confidence-bounded constraints, so the design tolerates the
  uncertainty.

## Key numbers (acceptance)

- The **deterministic optimum** is the canonical Sellar design `z ≈ (1.9776, 0)`,
  `x ≈ 0`, **`obj = 3.183394`** — identical to Lessons 2–4. It holds `g1` exactly, so
  under uncertainty it violates `g1` (`y1 ≥ 3.16`) **~50%** of the time; `g2` never binds.
- **PCE vs. Monte Carlo** at that design: `obj` mean ≈ 3.185 and std ≈ 0.388 agree to
  ~4 significant figures, and `P(g1 violated) ≈ 50%` matches — using **60** model runs
  (PCE) vs. **100,000** (MC). Sobol of `obj` is dominated by `a3` (≈0.70) and `a0`
  (≈0.28); `a1`, `a2` barely matter at this design.
- The **robust optimum** (`z ≈ (2.10, 0)`, `x ≈ 0.06`) raises `y1` (mostly via `z1`)
  to drive `P(g1 violated)` down to **~2.5%** (the 95% two-sided CI target), raising the
  mean objective from **≈ 3.18 to ≈ 3.68** — reliability costs performance. (UQPCE's CI
  resampling uses NumPy's global RNG, so the script seeds it for reproducibility.)
