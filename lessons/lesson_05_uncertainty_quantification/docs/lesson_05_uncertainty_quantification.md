# Lesson 5 — Uncertainty quantification

Lessons 2–4 treated every coefficient as exactly known. Real
designs live with uncertainty — tolerances, material scatter, operating conditions.
This lesson makes four Sellar parameters *random*, propagates that uncertainty to the
outputs, and then **reformulates the optimization in terms of statistics** so the
design is reliable, not just optimal-on-paper. It uses NASA's **UQPCE**
polynomial-chaos tooling, applied to the **same canonical Sellar problem** from
Lessons 2–4 — so the deterministic (mean-value) optimum is the familiar
`f* = 3.183394`, and adding the scatter is the only new ingredient.

Every script is runnable and writes committed `outputs/` (PNG/MD) so the figures
render on GitHub without re-running. Run from the repository root with the
`eng-des-opt-course` environment active. Scripts 3–4 need the `uqpce` package
(`pip install .[uq]`); scripts 1–2 need only numpy/scipy.

## The uncertain Sellar model

This is the **same canonical Sellar problem as Lessons 2–4**, with four coefficients
turned into random *multiplicative* factors. Crucially, **every factor has mean 1**,
so at the mean values the equations reduce exactly to the classic Sellar MDA and the
deterministic optimum is the familiar `f* = 3.183394` (OpenMDAO's canonical result).

```
Discipline 1:  y1  = a0*z1^2 + z2 + x - 0.2*y2          (a0      -> inside the MDA)
Discipline 2:  y2  = a1*sqrt(y1) + a2*z1 + z2           (a1, a2  -> inside the MDA)
Objective:     obj = x^2 + z2 + a3*y1 + exp(-y2)        (a3      -> after the MDA only)
Constraints:   g1  = 3.16 - y1 <= 0,   g2 = y2 - 24 <= 0   (classic Sellar)
```

with `a0 ~ N(1, 0.06)`, `a1 ~ U(0.9, 1.1)`, `a2 ~ N(1, 0.05)`, `a3 ~ N(1, 0.10)`
(`N(mean, std)`, `U(low, high)`, all independent). The factors sit on terms that are
**non-zero at the optimum** (`z1`, `sqrt(y1)`, `y1`) so each one actually influences
the response there. At the deterministic optimum `g1` is active (`y1 = 3.16`), so
scattering `a0` scatters `y1` and violates `g1` ~half the time; `g2` keeps a wide
margin and never binds.

## Problem formulation

### Given quantities

| Quantity | Value | Used in |
|---|---|---|
| Constants | `0.2` (coupling gain), `3.16` (lower limit on `y1`), `24` (upper limit on `y2`) | all |
| Uncertain parameters `a = (a0, a1, a2, a3)` | distributions above (`input.yaml`) | scripts 1–4 |
| Mean values `ā = E[a]` | `(1, 1, 1, 1)` | deterministic problem |
| Monte Carlo draws `a^(i)` | 100,000 (`sample_uncertain`) | script 2; reference/verification in 3–4 |
| Collocation points `a^(k)`, `k = 1..N` | `N = 60`, `run_matrix.dat` (seed 7) | scripts 3–4 |
| PCE order | 2 (15 basis terms in 4 variables) | scripts 3–4 |
| Significance `α` | 0.05 → two-sided 95% CI, so `CI_up` = 97.5th percentile | script 4 |

**Design variables** (both optimization problems): `z1 ∈ [−10, 10]` and
`z2 ∈ [0, 10]` (global, shared by both disciplines), `x ∈ [0, 10]` (local to
discipline 1). Start point `(z1, z2, x) = (5, 2, 1)`.

**State (coupling) variables** `y1, y2` are *not* design variables: for given
`z, x, a` the MDA determines them, and the optimizer sees only `z, x` (MDF
architecture, as in Lessons 2–4).

### MDA in residual form

For any value of the parameters, the coupled states `(y1, y2)` solve

```
R1(y1, y2; z, x, a0)  = y1 − (a0·z1² + z2 + x − 0.2·y2) = 0
R2(y1, y2; z, a1, a2) = y2 − (a1·√y1 + a2·z1 + z2)      = 0
```

and the objective and constraints are then evaluated explicitly from the converged states:

```
f(z, x, y1, y2; a3) = x² + z2 + a3·y1 + exp(−y2)
g1(y1) = 3.16 − y1,      g2(y2) = y2 − 24
```

### Deterministic problem (parameters fixed at their means)

```
minimize    f(z, x, y1, y2; ā3)
w.r.t.      z1 ∈ [−10, 10],  z2 ∈ [0, 10],  x ∈ [0, 10]
subject to  g1 = 3.16 − y1 ≤ 0
            g2 = y2 − 24   ≤ 0
where       R1(y1, y2; z, x, ā0) = 0
            R2(y1, y2; z, ā1, ā2) = 0          (one MDA, 2 unknowns)
```

With `ā = (1, 1, 1, 1)` this *is* classic Sellar: `f* = 3.183394` at
`z = (1.9776, 0)`, `x = 0`, `y1 = 3.16` (`g1` active), `y2 = 3.7553`. Solved by
`deterministic_optimum()` (SciPy SLSQP around the numpy fixed-point MDA).

### Forward UQ (scripts 2–3): no optimization

```
fix         (z, x) = deterministic optimum
for each    sample a^(i):
              solve  R1(y1, y2; z, x, a0^(i)) = 0,  R2(y1, y2; z, a1^(i), a2^(i)) = 0
              → y1^(i), y2^(i)
              evaluate  f^(i) = f(z, x, y1^(i), y2^(i); a3^(i)),  g1^(i),  g2^(i)
report      mean, std, 95% CI, P(g1^(i) > 0), Sobol indices
```

### Robust problem (script 4)

```
minimize    E[f]                          (PCE mean of f^1..f^N)
w.r.t.      z1 ∈ [−10, 10],  z2 ∈ [0, 10],  x ∈ [0, 10]
subject to  CI_up(g1) ≤ 0                 (97.5th percentile of g1, from the PCE)
            CI_up(g2) ≤ 0
where, for every collocation point k = 1..N  (N = 60):
            R1(y1^k, y2^k; z, x, a0^k)  = 0
            R2(y1^k, y2^k; z, a1^k, a2^k) = 0
            f^k  = x² + z2 + a3^k·y1^k + exp(−y2^k)
            g1^k = 3.16 − y1^k,    g2^k = y2^k − 24
```

The MDA now has `2N = 120` unknowns: `N` copies of the same 2-equation system, one per
collocation point. Every copy sees the same `z, x` but its own `a^k`, so the copies are
independent and the Jacobian is block-diagonal (60 blocks of 2×2). `SellarMDA(vec_size=60)`
solves them together with Newton + `DirectSolver` at every optimizer iteration. UQPCE
then fits an order-2 PCE to each response vector (`f^1..N`, `g1^1..N`, `g2^1..N`):
`E[f]` is the PCE's constant coefficient, and `CI_up` is the 97.5th percentile of
samples drawn from the fitted PCE. Result: `z ≈ (2.096, 0)`, `x ≈ 0.062`,
`E[f] ≈ 3.68`, `P(g1 violated) ≈ 2.5%`.

### How the uncertainty enters the MDA

| Parameter | Distribution | Enters | Scales | Effect |
|---|---|---|---|---|
| `a0` | `N(1, 0.06)` | `R1` (discipline 1) | `z1²` | shifts `y1` directly; accounts for almost all of the `y1` (hence `g1`) scatter |
| `a1` | `U(0.9, 1.1)` | `R2` (discipline 2) | `√y1`, the coupling term | changes how strongly `y1` feeds back through `y2` |
| `a2` | `N(1, 0.05)` | `R2` (discipline 2) | `z1` | shifts `y2`, which returns to `y1` through the `−0.2·y2` term |
| `a3` | `N(1, 0.10)` | objective only, **not the MDA** | `y1` | scatters `f` only; `y1`, `y2`, `g1`, `g2` do not depend on `a3` |

So `a0`, `a1`, `a2` make the **MDA** uncertain: the converged states `y1, y2`, and
with them both constraints, become random. `a3` makes only the **objective** uncertain.
That is why `a3` dominates the Sobol indices of `obj` (≈0.70) yet has no effect at all on
the probability of violating `g1`.

## Forward UQ and the robust reformulation

In short (full statements in [Problem formulation](#problem-formulation)):

```
deterministic:   min  obj           s.t.  g <= 0            (ignore the scatter)
robust:          min  E[obj]         s.t.  CI_upper(g) <= 0   (feasible with high probability)
```

(The constraints are in classic `g <= 0` form, so robust feasibility requires the
*upper* confidence bound `CI_upper(g) <= 0`. With `α = 0.05` and a two-sided interval,
`CI_upper` is the 97.5th percentile of `g`, so about 2.5% of draws can still violate
the constraint. This is a probabilistic guarantee, not a worst-case one. A true
worst-case guarantee is impossible here: with normal inputs, `y1` (and so `g1`) has no
finite worst case.)

**Monte Carlo** draws many input samples and runs the model at each — simple and
trusted, but expensive. **Polynomial chaos (UQPCE)** fits a polynomial in the random
inputs from a small *designed* set of runs, then reads `mean`/`variance` straight off
the coefficients and samples the cheap surrogate for the rest — the same statistics
for ~1000× fewer true model runs, which is what makes UQ affordable *inside* an
optimizer.

## What is fixed and what is sampled (MDA vs. MDO)

Scripts 2 and 3 are **forward UQ of one fixed design**, not optimization under
uncertainty. Both follow the same three steps:

1. **Optimize once, deterministically.** `deterministic_optimum()` runs SLSQP with every
   factor at its mean (`a_i = 1`, i.e. classic Sellar) and returns `z ≈ (1.9776, 0)`,
   `x ≈ 0`. This is the only optimization in scripts 2–3.
2. **Freeze that design.** For every sample of `(a0, a1, a2, a3)`, solve only the
   coupled **MDA** (`y1 ↔ y2`; `solve_mda`, vectorized fixed-point iteration) at the
   frozen `z`, `x`. Each sample is an MDA solve — nothing is re-optimized per sample.
3. **Collect statistics** of `obj`, `g1`, `g2` over the samples.

| Script | Design `z`, `x` | Samples of `a0..a3` | True MDA solves |
|---|---|---|---|
| 2 — Monte Carlo | fixed at the deterministic optimum | 100,000 random draws | 100,000 (+ 6 × 30,000 for the Sobol indices) |
| 3 — PCE (UQPCE) | fixed at the same deterministic optimum | 60 UQPCE collocation points (`run_matrix.dat`) | 60 to fit the PCE; the fitted PCE is then sampled 100,000 times (cheap), and 100,000 true MDA solves on the same draws serve only as the reference |
| 4 — robust opt. | **free** — SLSQP moves it | the same 60 collocation points, at every iteration | 60 per optimizer iteration |

So scripts 2–3 answer *"how does the design we built while ignoring the scatter behave
once the inputs scatter?"* — and the answer (`g1` violated ~50% of the time) motivates
script 4. MDO and UQ are combined only in **script 4**: the design variables are
free, and at every optimizer iteration the MDA is solved at all 60 collocation points
at once (`SellarMDA(vec_size=60)`), UQPCE turns those responses into `obj:mean` and
`con:ci_upper`, and SLSQP optimizes on those statistics. The XDSMs show the same split:
`sellar_forward_uq.*` takes `z, x` as a fixed input and has no optimizer;
`sellar_robust_opt.*` wraps the UQPCE group in one.

None of the scripts **re-optimizes for each sample** of `a`. That would give the
scatter of the *optimal design* — how the best design would move if `a` were known
before designing — which is a different question from how one built design performs
under scatter.

## Terminology cheat sheet

- **Aleatory** uncertainty — irreducible randomness, modeled with a distribution.
  **Epistemic** uncertainty — lack of knowledge, often modeled with intervals.
- **Forward propagation** — pushing input distributions through the model to get the
  output distribution. **Confidence interval** — the `(1 − significance)` central
  range of a response (here 95%).
- **Sobol indices** — variance-based global sensitivity: the fraction of output
  variance attributable to each input (`S_i` first-order, `S_Ti` total).
- **Polynomial chaos expansion (PCE)** — a surrogate expanded in orthogonal
  polynomials of the random inputs; **collocation / run matrix** — the designed
  sample points where the true model is run to fit it.
- **Robust optimization** — optimize a statistic of the objective (`E[obj]`) subject
  to probabilistic/confidence-bounded constraints, so the design tolerates the
  uncertainty.

## Key numbers (acceptance)

- The **deterministic optimum** is the canonical Sellar design `z ≈ (1.9776, 0)`,
  `x ≈ 0`, **`obj = 3.183394`** — identical to Lessons 2–4. It holds `g1` exactly, so
  under uncertainty it violates `g1` (`y1 ≥ 3.16`) **~50%** of the time; `g2` never binds.
- **PCE vs. Monte Carlo** at that design: `obj` mean ≈ 3.185 and std ≈ 0.388 agree to
  ~4 significant figures, and `P(g1 violated) ≈ 50%` matches — using **60** model runs
  (PCE) vs. **100,000** (MC). Sobol of `obj` is dominated by `a3` (≈0.70) and `a0`
  (≈0.28); `a1`, `a2` barely matter at this design.
- The **robust optimum** (`z ≈ (2.10, 0)`, `x ≈ 0.06`) raises `y1` (mostly via `z1`)
  to drive `P(g1 violated)` down to **~2.5%** (the 95% two-sided CI target), raising the
  mean objective from **≈ 3.18 to ≈ 3.68** — reliability costs performance. (UQPCE's CI
  resampling uses NumPy's global RNG, so the script seeds it for reproducibility.)
